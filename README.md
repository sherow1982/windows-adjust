## 🚀 الاستخدام

1. افتح الموقع: [windows-adjust](https://sherow1982.github.io/windows-adjust/)
2. ابحث عن التوبيك المطلوب
3. اضغط "فتح" للوصول للأوامر
4. اضغط على الكود لنسخه
5. افتح CMD/PowerShell كـ Admin
6. الصق الأمر ونفذه
