## 🚲 ملاحظات وتحذيرات

⚠️ **مهم جيداً:**

- ✅ اعمل **System Restore Point** قبل أي تعديلات
- ✅ استخدم حساب **Administrator**
- ✅ قرا الآمر بعناية **قبل نسخ**
- ✅ **انسخ والزم - لا تخمن** الأوامر
- ✅ معظم العمليات تحتاج **إعادة تشغيل**
