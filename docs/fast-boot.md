# تسريع إقلاع الويندوز

## تفعيل Fast Startup

1. اضغط `Win + R` واكتب `powercfg.cpl`
2. اختر **Choose what the power button does**
3. اختر **Change settings that are currently unavailable**
4. فعّل **Turn on fast startup**
5. اضغط Save changes

## تعطيل البرامج غير الضرورية

1. اضغط `Ctrl + Shift + Esc` (Task Manager)
2. اذهب إلى **Startup** tab
3. عطّل البرامج غير المهمة
