# تفعيل Ultimate Performance Mode

## عبر PowerShell (Admin)
```powershell
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
```

## عبر GUI
1. افتح Control Panel → Power Options
2. ستجد الآن **Ultimate Performance**
3. اختره

## ما هو
خطة طاقة أعلى من High Performance تلغي كل أوضاع التوفير

## ملاحظات
- يستهلك كهرباء أكثر
- أفضل للأجهزة المكتبية
